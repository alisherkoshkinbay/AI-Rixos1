# LMS — Оқу платформасы

**Тақырып:** Курстар, тапсырмалар және бағалау  
**Автор:** Нұрқасым Арулан  
**Топ:** ИС 23-10К  
**Технология:** Java 17, Swing, Maven

## IntelliJ IDEA-да іске қосу
1. Архивті ашыңыз.
2. IntelliJ IDEA → **File → Open** → `LMS_IntelliJ_Project` бумасын таңдаңыз.
3. Maven жобасы ретінде жүктелуін күтіңіз.
4. `src/main/java/kz/edu/lms/Main.java` файлын ашыңыз.
5. Жасыл **Run** батырмасын басыңыз.

## Қолданылған паттерндер
- **Composite** — курс → модуль → тапсырма ағашын құру.
- **Strategy** — бағалау алгоритмін ауыстыру: пайыздық, рубрикалық, pass/fail.
- **Observer** — баға өзгергенде Dashboard және NotificationPanel автоматты жаңаруы.
- **Template Method** — тапсырманы орындау процесінің жалпы қаңқасы.
- **Factory Method** — тапсырма түріне қарай Quiz, Coding, Essay объектісін жасау.

Интерфейсте курс таңдау, тапсырма ашу, тапсырма қосу, бағалау стратегиясын ауыстыру, тапсырманы орындау, баға қою, хабарламаны тазалау және жаңарту батырмалары бар.
