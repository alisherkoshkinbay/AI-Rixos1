LMS — Learning Management System

Жобаның сипаттамасы

Бұл жоба Java тілінде жасалған оқытуды басқару жүйесі (LMS). Жүйе оқу курстарын, студенттерді және оқу материалдарын басқаруға арналған.

Қолданылатын технологиялар

* Java
* IntelliJ IDEA
* Maven

Негізгі мүмкіндіктері

* Оқу курстарын басқару
* Студенттер туралы ақпарат сақтау
* Оқу материалдарын ұйымдастыру
* Оқу процесін басқару

Іске қосу

1. Жобаны IntelliJ IDEA бағдарламасында ашыңыз.
2. Maven тәуелділіктерін жүктеңіз.
3. Main.java файлын іске қосыңыз.
